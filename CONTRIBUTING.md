# Contributing to Latch

Contributions are welcome when they preserve the project’s accessibility and security boundaries.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Run `npm run check`.
3. Test the form with a keyboard and at narrow viewport widths.
4. Verify every error is associated with its field and announced correctly.
5. Explain the user-facing impact of the change.

Do not add real credentials, authentication secrets, tracking scripts, or client-side password storage.
